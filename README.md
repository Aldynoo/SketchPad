# SketchPad

The page generates a grid of squares that can be "drawn" on by hovering over them with the mouse. Every hover gives the square a random color and slowly increases its opacity.

## What I practiced

- DOM manipulation
- Creating elements with JavaScript
- Event listeners
- Flexbox
- Working with user input
- Changing styles dynamically

## Features

- Default 16x16 grid on page load
- Custom grid resizing
- Random RGB coloring
- Progressive darkening effect
- Grid size validation

## How to use

1. Enter a number between 2 and 99
2. Click **Resize Grid**
3. Hover over the grid to draw
